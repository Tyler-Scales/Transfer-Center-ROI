# Hospital Transfer Center ROI Calculator

## Overview

This is a full-stack web application designed to calculate return on investment (ROI) for hospital transfer center operations. The application features a React frontend with TypeScript and a Node.js/Express backend, utilizing modern web development practices and a comprehensive UI component library.

## System Architecture

### Frontend Architecture
- **Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS with shadcn/ui component library
- **State Management**: React Query (TanStack Query) for server state
- **Routing**: Wouter for lightweight client-side routing
- **Form Handling**: React Hook Form with Zod validation
- **UI Components**: Radix UI primitives wrapped in custom components

### Backend Architecture
- **Runtime**: Node.js with Express.js framework
- **Language**: TypeScript with ES modules
- **Database**: PostgreSQL with Drizzle ORM
- **Database Provider**: Neon Database (serverless PostgreSQL)
- **Session Management**: Express sessions with PostgreSQL storage
- **Development**: Hot reloading with Vite integration

### Build System
- **Frontend Build**: Vite with React plugin
- **Backend Build**: esbuild for production bundling
- **Development**: Concurrent frontend and backend development with HMR
- **TypeScript**: Strict mode with path mapping for clean imports

## Key Components

### Calculator Engine
The ROI calculator uses predefined constants and formulas to compute:
- Total annual transfers based on staffed beds
- Investment costs and operational savings
- Revenue from leakage recapture and new growth
- Net financial benefits and final ROI percentage

### UI Components
Comprehensive component library based on shadcn/ui including:
- Form controls (inputs, selects, checkboxes)
- Layout components (cards, separators, grids)
- Navigation elements (menus, breadcrumbs)
- Feedback components (toasts, alerts, progress bars)
- Data display (tables, charts, badges)

### Storage Layer
- **Development**: In-memory storage implementation
- **Production**: PostgreSQL with Drizzle ORM
- **Schema**: User management with extensible structure
- **Migrations**: Automated database schema management

## Data Flow

1. **User Input**: Hospital staff enter staffed bed count via the web interface
2. **Calculation**: Frontend performs ROI calculations using predefined business constants
3. **Display**: Results are formatted and displayed in an intuitive dashboard
4. **Persistence**: User sessions and data can be stored in PostgreSQL
5. **API Communication**: RESTful API endpoints handle data exchange
